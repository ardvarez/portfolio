BAGIAN 1 // ANALISIS SISTEM & BISNIS

📋 Perancangan Arsitektur Kebutuhan Bisnis & Logic Formulasi AHI

Business Analyst Scope
Scope Analisis Kebutuhan & Logika Bisnis:
  • Formulasi Asset Health Index (AHI): Membedah & memformulasikan algoritma perhitungan skor kesehatan trafo berdasarkan kombinasi data DGA Gas Analysis, Thermovision, Dielectric Breakdown Oil, dan inspeksi visual harian.
  • Konsolidasi 11+ Data Source Legacy: Menggabungkan data historis inspeksi gardu induk yang terfragmentasi di 11 database legacy menjadi satu arsitektur skema data yang terstandarisasi.
  • Arsitektur Row-Level Security (RLS): Menyusun aturan tata kelola keamanan data terisolasi berdasarkan hierarki wilayah kerja (UP3 / ULTG / UID) sehingga user unit hanya dapat mengelola aset wilayahnya sendiri.
  • Requirement Documentation (BRS & SDD): Mengarang dokumen spesifikasi teknis lengkap yang menjembatani komunikasi antara Business Process Owner (BPO) dan tim developer/QA.

BAGIAN 2 // KEMAMPUAN TEKNIS & PERFORMANCE TESTING

⚡ Pengujian Performa (Stress Testing), Metric Benchmark, & Tuning Query

Technical Engineering Scope
Scope Pengujian Teknis & Rekayasa Performa:
  • Simulasi Peak Concurrency Load Testing: Merancang & mengeksekusi skenario stress test menggunakan beban 105 Virtual Users (VU) secara simultan dengan total 88.200 request untuk menguji batas ketahanan server.
  • Pencapaian 0.00% Stress Error Rate: Memastikan keandalan backend API tetap stabil dengan tingkat kegagalan 0.00% pada throughput puncak 147.2 req/sec selama pengujian intensif.
  • Benchmarking & Tuning Latensi Query: Mengoptimalkan performa query SQL kompleks dengan indexing pada filter territorial RLS (`unit_id`, `ultg_code`), menekan rata-rata waktu respon hingga 672ms (P95: 1.12s).
  • API Validation & Quality Assurance: Menjalankan otomatisasi pengujian API (Postman) dan verifikasi skenario positif/negatif sebelum implementasi di lingkungan staging & produksi.
